# Sequential networks

Reference: https://www.hkr.se/kurs/dt102a/kursplan/ (page returned template; below is a course-aligned learning plan)

## Overview
Sequential circuits depend on current inputs and previous states; covers flip-flops, registers, counters, and state machines.

## Learning objectives
- Understand flip-flops (SR, D, JK, T) and edge vs level triggering
- Design synchronous counters and shift registers
- Model and implement finite state machines (Mealy and Moore)
- Analyze setup/hold times and clocking issues

## Topics to learn
- Latches vs flip-flops, timing parameters
- Register files and synchronous design principles
- State minimization and state machine design methods
- Debouncing, clock domain crossing basics

## Suggested exercises
- Design a synchronous mod-N counter and simulate
- Create state machine for simple controller (traffic light, vending logic)
