# Data storage

Reference: https://www.hkr.se/kurs/dt102a/kursplan/ (page returned template; below is a course-aligned learning plan)

## Overview
Fundamentals of how digital information is stored and organized: bit/byte, registers, memory hierarchy, and file representation.

## Learning objectives
- Understand bit/byte/word organization
- Learn about memory hierarchy: registers, caches, RAM, secondary storage
- Know common data encodings (ASCII, UTF-8) and data structures on disk

## Topics to learn
- Storage units and addressing
- Endianness
- Volatile vs non-volatile memory
- File systems basics and block organization
- Error detection and correction (parity, checksums, ECC)

## Suggested exercises
- Explore hex dumps and interpret bytes as text/integers
- Simulate memory read/write with simple code and show endianness effects
- Implement simple parity or checksum checker
