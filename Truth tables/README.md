# Truth tables

Reference: https://www.hkr.se/kurs/dt102a/kursplan/ (page returned template; below is a course-aligned learning plan)

## Overview
Truth tables are the foundation for describing boolean functions and designing logic circuits.

## Learning objectives
- Construct truth tables for logical expressions and circuits
- Use truth tables to verify equivalence and simplify logic
- Translate truth tables into boolean expressions and gate-level circuits

## Topics to learn
- Basic logic operators (AND, OR, NOT, XOR, NAND, NOR)
- Generating truth tables for multi-input functions
- Minterms, maxterms, and canonical forms
- Using truth tables to test circuit behavior

## Suggested exercises
- Build truth tables for common functions and verify with simulation tools
- Convert tables to sum-of-products and product-of-sums
