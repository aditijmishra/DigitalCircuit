# Memories and IO

Reference: https://www.hkr.se/kurs/dt102a/kursplan/ (page returned template; below is a course-aligned learning plan)

## Overview
Focused study of memory systems and input/output interfacing between processors and peripherals.

## Learning objectives
- Understand DRAM vs SRAM and memory organization
- Study memory-mapped vs port-mapped I/O
- Learn common I/O protocols (UART, SPI, I2C) and interrupt basics
- Grasp DMA concepts and basic peripheral interfacing

## Topics to learn
- Memory timing, refresh, and caching implications
- Bus structures and address decoding
- Polling vs interrupt-driven I/O and DMA transfers
- Simple peripheral protocols and example circuits

## Suggested exercises
- Interface a simple peripheral in simulation (UART echo)
- Design address decoding logic for memory-mapped devices
