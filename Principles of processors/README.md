# Principles of processors

Reference: https://www.hkr.se/kurs/dt102a/kursplan/ (page returned template; below is a course-aligned learning plan)

## Overview
Introduction to how processors execute instructions: datapath, control unit, instruction cycles, and basic pipelining.

## Learning objectives
- Understand instruction execution cycle (fetch, decode, execute)
- Study basic datapath components and control signals
- Learn simple pipelining concepts and hazards
- Link instruction set behavior to hardware structures

## Topics to learn
- CPU datapath: ALU, registers, program counter, instruction register
- Control unit: hardwired vs microprogrammed control
- Basic pipeline stages and hazard resolution (stalls, forwarding)
- Simple instruction set and assembly-level effects

## Suggested exercises
- Trace instruction execution on a simple five-stage pipeline
- Build a basic single-cycle CPU datapath in simulator or HDL
