# Combinatorial networks

Reference: https://www.hkr.se/kurs/dt102a/kursplan/ (page returned template; below is a course-aligned learning plan)

## Overview
Design and analysis of combinational logic networks—circuits whose outputs depend only on current inputs.

## Learning objectives
- Design adders, multiplexers, decoders, encoders, and comparators
- Implement logic minimization into practical circuits
- Analyze propagation delay and hazard conditions

## Topics to learn
- Binary adders (half, full), ripple-carry, carry-lookahead basics
- Multiplexers, demultiplexers, encoders, decoders
- Comparator circuits and priority encoders
- Combinational circuit timing and hazards

## Suggested exercises
- Design and simulate a 4-bit adder and a ALU-style combinational block
- Build multiplexers and use them to implement arbitrary functions
