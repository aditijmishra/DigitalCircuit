# Main Components of a Computer and Program Execution

## 1. What is a computer?

A **computer** is an electronic machine that receives data, processes it according to instructions, stores information, and produces results.

A computer can be thought of as four basic activities:

**Input → Processing → Storage → Output**

---

## 2. CPU

The **CPU (Central Processing Unit)** is the main processing unit of a computer. It executes program instructions and performs calculations.

The CPU contains several important parts.

### ALU

The **Arithmetic Logic Unit (ALU)** performs:

- Addition and subtraction
- Other arithmetic operations
- Comparisons
- Logical operations

### Control Unit

The **Control Unit (CU)** coordinates the activities of the CPU.

It tells other parts of the computer what to do and in what order.

### Registers

**Registers** are very small and very fast storage locations inside the CPU.

They temporarily hold information such as data, addresses, and instructions being processed.

---

## 3. Memory

### RAM

**RAM (Random Access Memory)** temporarily stores programs and data that the computer is currently using.

RAM is **volatile**, meaning its contents are normally lost when the computer is turned off.

### Storage

Storage devices such as **SSDs and hard drives** keep data even when the computer is turned off.

They can store:

- Operating systems
- Programs
- Documents
- Photos
- Videos

---

## 4. Input and output

### Input devices

Input devices allow information to enter a computer.

Examples:

- Keyboard
- Mouse
- Microphone
- Camera
- Touchscreen

### Output devices

Output devices present information to the user.

Examples:

- Monitor
- Speakers
- Printer

---

## 5. Motherboard and buses

The **motherboard** is the main circuit board that connects many computer components.

**Buses** are communication pathways that allow components to exchange information.

---

## 6. How a program is executed

A CPU generally follows a repeated process called the **fetch-decode-execute cycle**.

### Step 1: Fetch

The CPU gets the next instruction from memory.

### Step 2: Decode

The Control Unit determines what the instruction means and what operation needs to be performed.

### Step 3: Execute

The CPU performs the required operation.

For example, it might add two numbers or move data.

### Step 4: Store the result

The result may be placed in a register or memory.

The CPU then repeats the cycle for the next instruction.

**Fetch → Decode → Execute → Repeat**

---

## 7. Example

Suppose a program contains an instruction to add two numbers.

1. The CPU fetches the instruction.
2. The Control Unit decodes it.
3. The required numbers are obtained.
4. The ALU performs the addition.
5. The result is stored.
6. The CPU moves to the next instruction.

## 8. Key idea

**The CPU executes instructions, memory provides fast temporary storage, permanent storage keeps data, input devices provide data, and output devices present results.**
